# 數獨產生器

一個具有 AI 輔助功能的數獨遊戲，使用 Google Gemini API 提供智能提示。

## 功能特點

1. **多難度等級**
   - 簡單
   - 中等
   - 困難

2. **AI 輔助系統**
   - 整合 Google Gemini API
   - 智能提示功能
   - API Key 安全儲存

3. **遊戲機制**
   - 錯誤次數限制（3次）
   - 即時錯誤提示
   - 自動遊戲結束機制
   - 重新開始功能

4. **存檔系統**
   - 保存遊戲進度
   - 載入已保存的遊戲
   - 記錄錯誤次數和難度設定

## 使用方法

1. **開始遊戲**
   - 選擇難度等級
   - 點擊「新遊戲」開始

2. **AI 提示功能**
   - 輸入 Google API Key
   - 點擊「儲存」以啟用提示功能

3. **遊戲規則**
   - 每行、每列、每個 3x3 方格中數字 1-9 不能重複
   - 輸入錯誤數字會顯示為紅色
   - 累計三次錯誤將結束遊戲
   - 可隨時使用 AI 提示獲取幫助

4. **存檔功能**
   - 使用「儲存遊戲」保存當前進度
   - 使用「載入遊戲」繼續先前的遊戲

## 技術實現

- HTML5
- CSS3
- JavaScript
- Google Gemini API

## 注意事項

- 需要有效的 Google API Key 才能使用提示功能
- 建議使用現代瀏覽器以獲得最佳體驗
- 每次遊戲限制三次錯誤嘗試
